# Emmanuele Sacco — Portfolio

CV portfolio personale statico, progettato per raccontare attività, competenze e metodo professionale con un focus su Microsoft 365, Azure, Intune ed Entra ID.

## Struttura

- `index.html` — contenuti e struttura semantica
- `styles.css` — design system, layout responsive e animazioni
- `script.js` — navigazione mobile, reveal, progress bar e copia email

## Avvio locale

Il progetto non richiede build o dipendenze. Apri `index.html` oppure avvia un server statico nella cartella del progetto.

Esempio con Python:

```bash
python -m http.server 4173
```

Poi visita `http://localhost:4173`.
